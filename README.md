# Business Diagnostic Tool

An interactive diagnostic system for rural and small businesses.

Most small business owners know something is wrong. They don't always know where. 
This tool walks them through a structured five-step process that narrows vague 
operational frustration into specific, actionable problem categories — missed calls, 
broken follow-up, scheduling failures, intake gaps, and more.

The result is clarity. A defined starting point instead of a list of symptoms.
